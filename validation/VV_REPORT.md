## 0. Errata for the 2026-11-15 report

| Previous claim | Status | Correction |
|---|---|---|
| Multilayer SAFE: S0 −40.43 % vs free glass, "interfacial flexural-shear mode" | **Wrong** | Sign error in the SAFE cross-coupling block, hidden by forced symmetrisation. Corrected laminate S0 is −1.0 % vs free glass (−0.2 % at the 150 kHz reference used by Tier-0). |
| Sponge boundary reflection 2.37 % | **Wrong** | Damping was ~10× too weak; measured reflection was ~74 %. Now sized for the layer: ~11 % for a 12-cell (1.4 λ) layer. |
| Grid convergence order 2.12 → 0.25 | **Not meaningful** | Cell geometry was offset by dx/2 and the sensor sample was recorded one step late (both first-order errors). Fixed: observed order 1.93. |
| Reciprocity 0.0104 % on a heterogeneous medium | **Not meaningful** | The heterogeneity was assigned to an attribute the solver never read. Now tested with a real inclusion (self-adjoint flux form): 1.2e-15. |
| Tier-1 localisation 222.77 mm caused by edge reverberation | **Wrong cause** | Sensors sat inside the absorbing sponge and the grid had ~2.7 points per wavelength. With a correct setup Tier-1 localisation error is 5.8 mm (median). |
| "Tier-1 elastodynamic plate solver" | **Mislabelled** | It is a 2D scalar wave solver (no A0/S0 dispersion). |
| LightGBM macro-F1 0.9439, ECE 0.0304 (20,000 events) | **Not comparable** | The data were 99 % ADC-saturated, the held-out modules barely differed physically from training, and the task was binary with friction counted as crack. |
| 1D-ResNet macro-F1 0.7507 | **Invalid** | The network was never trained (random weights, no residual connection). |
| Physics V&V "ALL_PASS" in CI | **Invalid** | The fidelity-gap test compared random noise with itself; reciprocity and convergence were hard-coded PASS. |

## 3. Scale KPI benchmark (`validation/kpi_benchmark_summary.json`)

**Setup:** 5 module designs × 500 events (reduced from the planned 1,200 because the host had
< 1 GB free RAM). Train: MOD-1 standard 120, MOD-2 large 144 (2.8 mm glass), MOD-3 utility 60
(4.0 mm glass). Held-out test: MOD-4 glass-glass bifacial (POE), MOD-5 hot (55–75 °C).
10 event classes; untriggered crack events count as missed detections.

| KPI (PRD §14.1) | Target | Achieved | Status |
|---|---|---|---|
| Recall @ ≤ 1 false alarm / module-day | ≥ 0.98 | 0.00 — no threshold reaches the required FPR of 1e-4 (10,000 noise triggers/day assumed, `[UNSOURCED]`) | GAP |
| Classification macro-F1 (10 classes) | ≥ 0.95 | 0.53 [0.50, 0.56] features · 0.55 CNN · 0.60 ensemble | GAP |
| New-fracture detection | — | PR-AUC 0.91; precision 0.95 / recall 0.55 at p ≥ 0.5; crack trigger rate 0.77 | — |
| Localisation median (held-out cracks) | ≤ 15 mm | 35 mm overall (MOD-5: 13.3 mm; MOD-4 bifacial: 198 mm) | GAP |
| Localisation 90th percentile | ≤ 40 mm | 644 mm | GAP |
| Cell-ID accuracy | ≥ 0.95 | 0.51 (MOD-5 0.65; MOD-4 0.29) | GAP |
| Calibration (new-fracture ECE) | ≤ 0.05 | 0.17 (top-label ECE 0.21 after temperature scaling) | GAP |

Per-class F1 (feature model): crack initiation 0.70, crack growth 0.73, crack friction 0.58,
hail-induced crack 0.47, hail 0.25, rain 0.40, wind rattle 0.31, thermal tick 0.69, EMI 0.87,
handling tap 0.34.  Impacts (hail, tap, hail-crack) are the main confusions — all are normal
forces on the glass, which is physically expected.

**Open-set test** (handling taps withheld from training): 34 % flagged "unknown", 18 % false
"unknown" on known classes, 1.5 % mis-called as new fracture.

**Split-conformal sets** (α = 0.1, calibrated on training modules): coverage 0.68, mean set
size 1.6 — below the nominal 0.90 because the held-out modules are a distribution shift;
re-calibration per module design (or on real data) is required.

**Tier-1 localisation** (reflecting frame edges, 5 mm grid, 100 kHz): median 5.8 mm, P90 7.2 mm.

### Interpretation
* Physics and numerics are now verified; ML and localisation KPIs are **far from the PRD
  targets** on realistic synthetic data (ambient noise, reflections, sensor jitter,
  temperature error, weak far-field S0, ~30 dB source-level spread).
* Glass-glass modules are poorly localised: the laminate model treats only the *front* glass
  as the waveguide (`identify_fundamental_modes(waveguide_layer=0)`), which is wrong for
  symmetric glass-glass stacks. This is the most important open modelling item.
* The false-alarm KPI cannot be assessed meaningfully until the noise-trigger rate and noise
  distribution are measured in the field.
